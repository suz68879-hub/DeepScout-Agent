# AI Agent 应用开发面试题库

## 1. 谈谈你对 RAG 的理解
- 参考答案要点：检索增强生成的动机（幻觉/知识时效）；索引-检索-生成三段式；chunk 策略；重排
- 追问方向：如何评估检索质量；什么时候需要微调而不是 RAG

## 2. Function Calling 与 MCP 的区别
- 参考答案要点：工具调用协议；MCP 的标准化意义（client/server/stdio）；两者不是替代关系
- 追问方向：Agent 如何选择工具；工具调用失败怎么兜底

## 3. 如何评估一个 LLM 应用的效果
- 参考答案要点：离线评估集；LLM-as-a-Judge 及其校准；在线指标；回归护栏
- 追问方向：评分漂移怎么解决；小样本下怎么做评估

## 4. 多 Agent 编排有哪些模式
- 参考答案要点：流水线/监督者/辩论；状态共享；checkpoint 持久化；热冷路径分离
- 追问方向：多 Agent 的延迟与成本；什么场景值得多 Agent

## 5. 提示注入怎么防
- 参考答案要点：数据/指令隔离；输入输出 Schema 校验；工具白名单；权限最小化
- 追问方向：间接注入（检索内容带毒）；协议层与内容层护栏
