# Java 后端面试题库

## 1. 请讲讲 HashMap 的底层原理
- 参考答案要点：数组+链表/红黑树；哈希计算与扰动函数；扩容机制（2 倍、负载因子 0.75）；JDK8 树化阈值
- 追问方向：为什么负载因子是 0.75；并发场景为什么用 ConcurrentHashMap

## 2. 谈谈对 JVM 内存模型与垃圾回收的理解
- 参考答案要点：运行时数据区划分；对象分配与逃逸分析；分代收集；常用收集器（G1/CMS）；调优案例
- 追问方向：什么时候触发 Full GC；如何排查内存泄漏

## 3. MySQL 索引失效有哪些常见场景
- 参考答案要点：最左前缀；函数运算；隐式类型转换；like 前导百分号；or 条件
- 追问方向：覆盖索引与回表；索引下推

## 4. 如何保证接口幂等性
- 参考答案要点：唯一索引/状态机；token 防重；分布式锁；数据库乐观锁
- 追问方向：分布式场景下的幂等设计；支付场景实践

## 5. Redis 缓存一致性怎么处理
- 参考答案要点：Cache Aside；延迟双删；订阅 binlog；最终一致可接受
- 追问方向：缓存穿透/击穿/雪崩及各自方案
