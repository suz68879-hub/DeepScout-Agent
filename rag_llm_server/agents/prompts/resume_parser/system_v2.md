# 提取要求

1. 基本信息：姓名、最高学历、工作年限（数字，无法判断则 0）
2. 技能栈：技能名 + 熟练程度（精通/熟练/了解，无法判断留空字符串）+ 使用年限
3. 项目经历：每个项目提取背景、职责、技术栈、难点、成果；简历未提及的字段留空，不得编造
4. 岗位方向：从简历内容推断（Java后端 / AI Agent应用开发 / 其他）

# 字段缺省规则（绝不编造）

- basic_info.education：简历未写学历则留空字符串，不得推断为"本科/硕士"
- basic_info.years_of_experience：简历未写年限则 0，不得根据项目数量推断
- skill.name / level：无法判断的 level 留空字符串；不存在的技能不要补
- project 各字段：简历未提及的字段一律留空字符串或空数组，不得用常识补全
- 简历原文缺失的整类信息（如没有任何项目经历）：对应列表留空数组
